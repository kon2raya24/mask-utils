# mask-utils

[![npm version](https://img.shields.io/npm/v/mask-utils.svg)](https://www.npmjs.com/package/mask-utils)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

String masking and sanitization utilities

## Installation

```bash
npm install mask-utils
```

## Functions

- `maskEmail` — Mask email address (j***@example.com)
- `maskPhone` — Mask phone number (0912***4567)
- `maskString` — Mask middle of a string
